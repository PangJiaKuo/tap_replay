# TapReplay 手势回放（Android 宏录制/回放）

在手机端**录制你的点击与滑动序列**，之后一键**原样复刻**；支持**多版本管理**（保存/重命名/副本/导入导出）。

零第三方依赖的纯 Android 框架工程（Java），用 Android Studio 打开即可构建。

## 功能

| 功能 | 说明 |
|------|------|
| 录制 | 悬浮条点 ⏺ 后全屏捕获触摸：单击、长按、滑动、多指（每指独立轨迹，2px 高密度采样） |
| 盲录模式 | 录制中应用暂不响应（避免注入触摸打回捕获层形成自录自放循环）；录完点 ▶ 立即验证 |
| 回放 | 按**原始节奏**复刻：轨迹路径、单指真实时长、手势间真实间隔 |
| 坐标校准 | 绝对坐标（getRawX/Y）+ 物理分辨率记录；回放做**旋转变换 + 分辨率缩放 + 边界钳制** |
| 防误触 | 注入期间面板**整体隐藏**（注入触摸会命中最上层悬浮窗——这是 v1"多出点击"的根因）；录制/回放只留小条：**双击结束录制 / 长按停止回放** |
| 多版本 | 每次录制存一个版本：列表/重命名/**复制副本**/删除/**导出 JSON**/导入 |

## 构建

本 WSL 环境没有 Android SDK，请在有 Android Studio 的机器上构建：

1. Android Studio → **Open** 选择 `tap_replay/` 目录（等它自动同步 Gradle）
2. 手机开 USB 调试连上 → **Run ▶**；或 **Build → Build APK(s)** 生成安装包拷贝到手机安装

> 工程无 gradle wrapper jar（二进制无法随源码提供），Android Studio 会用本机 Gradle 同步，
> 或在有网环境执行 `gradle wrapper` 生成。

## 荣耀400（MagicOS 9）适配指南

本工程已内置荣耀适配（主页自动识别荣耀设备并高亮提示）：

1. **安装**：荣耀「纯净模式」会拦截侧载 APK——安装时按提示输入密码临时放行
   （设置 → 系统和更新 → 纯净模式）
2. **无障碍服务**：设置 → 辅助功能 → 无障碍 → 已安装的服务 → TapReplay → 开启
3. **保活三步**（主页有对应按钮，必做，否则悬浮条几分钟后被后台清理）：
   - **电池优化白名单**：一键直达申请
   - **自启动管理**：自动尝试打开手机管家应用启动管理（MagicOS 各版本路径自动降级）
   - **保活服务**：前台服务 + 常驻通知，悬浮条显示期间进程不会被杀
4. **建议**：录制期间用「三键导航」代替全面屏手势（设置 → 系统和更新 → 系统导航方式），
   避免底部手势区冲突；如有「防误触模式」且录制边缘手势失败，可临时关闭
5. 荣耀400 为 120Hz 高刷屏：采样按 2px 位移记录，与高刷新率无关，天然兼容
6. Android 15 注意：本工程 targetSdk 34 刻意不升 35（规避强制 edge-to-edge 与
   更严的 FGS 类型约束），在 Android 15 上以兼容模式稳定运行

## 使用

1. 首次打开 App，按主页提示完成两步授权：
   - **无障碍服务**：系统设置 → 无障碍 → 已下载的服务 → TapReplay → 开启
   - **悬浮窗权限**：按提示允许（部分机型无障碍悬浮层本身可用，授权更保险）
2. 主页点「显示悬浮控制条」，App 自动退到后台
3. 切到目标应用：
   - **⏺** 开始录制（屏幕泛淡红，顶部出现小条）→ 正常操作手机（**此时应用暂不响应**，这是刻意的盲录设计）→ **双击顶部小条**结束并自动保存
   - 保存后点 **▶** 立刻验证回放效果
   - **宏名按钮** 在多个版本间切换；回放时面板自动隐藏，顶部出现「**长按停止**」小条可中断
   - 空闲时按住控制条空白处拖动可换位置
4. 回主页管理版本：重命名 / 复制副本 / 导出 JSON 分享 / 导入

## 原理（为什么不需要 Root）

- **捕获**：`TYPE_ACCESSIBILITY_OVERLAY` 全屏悬浮层接收原始触摸（getRawX/Y 绝对坐标），
  按 pointerId 分指累积轨迹，2px 采样；全部手指抬起组成一个手势（含多指并行轨迹与真实间隔）
- **回放**：`AccessibilityService.dispatchGesture` 注入 `GestureDescription`。
  注意：注入的触摸会**命中最上层的无障碍悬浮窗**——所以回放期间面板必须隐藏
  （v1 的"多出点击"正是复刻的点击砸中了面板按钮；录制实时透传则形成自录自放循环，v2 已改盲录）
- **存储**：`macros/<id>.json`，一宏一文件，含分辨率、屏幕方向、每指轨迹点列与时长、手势间隔

## 已知限制

- 录制采用盲录：操作期间应用不响应，靠保存后回放验证；这是可靠性的代价
- 银行/支付/部分游戏类 App 会屏蔽注入触摸（安全策略），无法回放
- 锁屏、系统导航手势（返回/Home）不在捕获范围
- 回放按坐标复刻：目标 App 布局若发生变化（列表位置不同），结果会偏离——这正是多版本的意义
- 被系统杀掉无障碍服务后需重新开启（部分国产 ROM 需在后台管理中锁定本 App）
